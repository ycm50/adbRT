# AdbRT 产品设计

> 一句话：**把 `adb` / `fastboot` 那些记不住的命令，放回你已经在的地方。**

## 1. 定位

### 1.1 问题

`adb` 与 `fastboot` 是 Android 开发/玩机绕不开的两个工具，但：

- 参数位置敏感（`-s` 必须在子命令前，放错了要么报错、要么打到**另一台**手机上）；
- 有 40+ 个子命令，绝大多数人只记得 5 个；
- `fastboot flash` / `erase` / `unlock` 一旦搞错分区就是变砖；
- 命令行里粘贴路径要处理空格与引号。

### 1.2 解法

一个 Windows 桌面程序，**选设备 → 选命令 → 勾选项 → 看真实命令行 → 执行**。
关键点：**执行前就能看到即将运行的完整 argv**，并且可以一键复制。

### 1.3 目标用户

| 用户 | 场景 |
| --- | --- |
| 应用开发 | 装包、卸载、清数据、看日志、截屏 |
| 玩机用户 | 推拉文件、无线调试、fastboot 刷分区 |
| 支持/测试 | 快速定位某台设备的状态、抓 bugreport |

### 1.4 明确不做（Non-goals）

- ❌ **不写注册表**（唯一例外是安装器把目录写进用户 PATH）
- ❌ 不做资源管理器右键菜单（本项目已按用户要求移除该方向）
- ❌ 不内嵌 platform-tools（体积大、版本会漂），只指向用户已有目录
- ❌ 不做镜像投屏（scrcpy 是另一个产品）
- ❌ 不做 root 注入 / hook / 抓包，只用官方命令面
- ❌ 不自动 `kill-server`（会打断 Android Studio），只提供显式按钮

## 2. 决策记录

| ID | 决策 | 理由 |
| --- | --- | --- |
| D1 | 单窗口 GUI：左命令树 + 右参数/输出 | 命令面太长，不适合塞进菜单 |
| D2 | **argv 只有一个来源**（声明式命令表 → 构造器） | adb 参数顺序敏感，手拼字符串必然出错 |
| D3 | 当前设备是第一等公民，多设备强制 `-s` | 最危险的误操作是"命令打到了错误的手机" |
| D4 | 危险级别四档，Breaker 需手打序列号 | 变砖成本远高于一次误删文件 |
| D5 | 不写注册表；持久化只在 config.json | 绿色、可搬移、卸载无残留 |
| D6 | 安装器只改「用户 PATH」+ 桌面快捷方式 | 用户明确要求的能力边界 |
| D7 | 路径支持相对 / 绝对 / 环境变量 / `~` | 换机器、换目录不该让人改配置 |
| D8 | CLI 门面与 GUI 共用构造器 | 脚本化与界面必须行为一致 |

## 3. 功能

### 3.1 命令覆盖（52 条）

| 分组 | 条数 | 代表命令 |
| --- | --- | --- |
| 设备 | 12 | 设备列表、设备信息、重启到…、无线调试（tcpip/connect/pair）、root/unroot、重连、重启 adb 服务 |
| 应用 | 9 | 安装 APK、批量安装、卸载、启动、强停、清数据、授权、已安装列表、导出 APK |
| 文件 | 5 | 推送、拉取、文件浏览、新建目录、删除 |
| 屏幕与输入 | 6 | 截屏、录屏、点击、滑动、输入文本、按键 |
| Shell 与日志 | 6 | 执行命令、交互终端、实时日志、导出日志、bugreport、读属性 |
| Fastboot（专家） | 10 | 设备列表、重启、读变量、临时启动、切槽位、刷写、擦除、解锁、上锁、全量刷机 |
| 工具 | 4 | 设置、自检、关于、打开 platform-tools |

### 3.2 危险级别

| 级别 | 含义 | 交互 |
| --- | --- | --- |
| 安全 | 只读 | 直接执行 |
| 谨慎 | 改设备状态，可恢复 | 直接执行 |
| 破坏性 | 会丢数据（卸载/清数据/删文件） | 弹出二次确认 |
| **危险** | 可能变砖（fastboot 刷写/擦除/解锁） | 需**手打设备序列号**才放行 |

命令树上用 `-` / `!` / `!!` 前缀区分，右上角另有彩色徽标。

### 3.3 参数交互

- 每条命令的参数与选项由命令表**动态生成**，中文标签；
- 选项分四类：复选、单选组、值型（填了就进 argv）、复选+可选值；
- 「浏览…」按参数类型弹不同对话框（APK / 镜像 / 目录）；
- 面板下方常驻**将执行的命令**（深色代码块），可复制。

### 3.4 设备上下文

- 顶栏设备下拉，多设备时必须选一台；
- 只有一台在线设备时自动选中并记住；
- 设备状态不是 `device` 时（offline / unauthorized / recovery）给出中文解释。

## 4. 数据与边界

### 4.1 落盘位置

| 内容 | 位置 |
| --- | --- |
| 配置 | `%APPDATA%\AdbRT\config.json` |
| 日志 | `%LOCALAPPDATA%\AdbRT\logs\adbrt-<时间戳>.log` |
| 截屏 | `<用户>\Pictures\AdbRT\`（可配置） |
| 导出 APK / 日志 | `<用户>\Downloads\`（可配置） |

### 4.2 明确不落盘

- adb 私钥 / 授权凭据（交给 adb 自己）
- 无线调试配对码
- 设备上的任何内容（除用户主动导出）

## 5. 发布

| 项 | 规则 |
| --- | --- |
| 触发 | **只有 `workflow_dispatch`**（push / PR 都不跑） |
| 构建矩阵 | Debug + Release（`-DADB_WERROR=ON`） |
| 打包 | 复用 build 的 Release 产物，不重编译 |
| 发布 | **只有 build 与 package 全部成功**才建 tag；tag 号由人手动输入 |
| 版本号 | 唯一来源 `packaging/identity.json`，没有明确要求不递增 |

产物：`AdbRT-<版本>-win-x64.zip`（含 `app\`、安装/卸载脚本、说明、LICENSE）。
